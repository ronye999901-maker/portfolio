## 📌 Overview

A modern, high-performance developer portfolio built with **Next.js 16**, **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Framer Motion**. Designed with a futuristic dark cyberpunk aesthetic, interactive 3D particle systems, terminal emulation, dynamic project filtering, and real-time contact integration.

---

## ✨ Key Features

- **Cyberpunk UI & Visual Polish**: Glassmorphism cards, dynamic glowing gradients, Three.js starfields, and particle background simulations.
- **Interactive Terminal**: Custom command-line interface supporting `help`, `projects`, `skills`, `research`, `contact`, `clear`, and secret commands.
- **Engineered Project Showcase**: Deep technical breakdowns including system architecture pipelines, key performance stats, challenges solved, and live demo links.
- **Multi-Category Filter**: Instant category filtering across **AI / ML**, **Drone / UAV**, **E-Commerce**, **Web Development**, **Backend**, and **IoT**.
- **Research & Academic Milestones**: Highlighted semiconductor research from **IEDC IEM Kolkata** (*"Fabrication of GNR MOSFET using Machine Learning"*).
- **Responsive & Accessible**: Optimized for mobile, tablet, and ultra-wide displays with keyboard navigation and smooth motion effects.
